# Quote Calculator

A simple and efficient tool for calculating quotes and estimates, mainly for automotive repair shops but adaptable to various industries. It allows users to quickly generate accurate quotes based on customizable parameters, including labor costs, parts, taxes, and discounts.

## Features

- **Quick Calculations**: Rapidly compute quotes based on customizable parameters
- **Multiple Pricing Models**: Support for hourly rates, fixed prices, and project-based estimates
- **Save Locally**: Store quotes on your device for easy access and management
- **Export Options**: Export job templates and inventory data in CSV format
- **Tax Calculation**: Automatically calculate and apply tax to quotes
- **Discount Support**: Apply percentage or fixed-amount discounts
- **Professional Output**: Generate formatted quote summaries
- **Easy Configuration**: Simple setup and configuration options
- **Cost Breakdown**: Detailed itemization of quote components

## What It Does

Quote Calculator helps you:
- Generate professional quotes for clients quickly
- Maintain consistent pricing across projects
- Calculate complex pricing scenarios with multiple variables
- Track and organize quote information
- Export quotes in a readable format

## Usage

Simply run the calculator with your pricing parameters, and it will generate a detailed quote with all costs itemized and totaled.

## Installation

Clone the repository and follow the setup instructions in your project configuration.
