# Parts Interchange

For inventoried parts, allow user to setup custom interchange rules by:

- yearStart - yearEnd, make, model(s)
  AND/OR
- vehicle metadata i.e. transmissionType == "CVT" or EngineSize == "4.2" or CountryOfOrigin == "Canada"

Allow multiple interchanges for a part.

Whenever a user is creating a quote, parts that match the vehicle according to the interchange should be highlighted green as "Exact Fit" to make quotes easier.
